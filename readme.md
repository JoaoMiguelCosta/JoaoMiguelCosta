## 🚀 Featured Projects

### Farmácia Santa Casa

Full-stack management platform developed to manage workflows between a pharmacy, a Santa Casa organisation and system administrators.

#### Highlights

- JWT authentication and role-based access control
- Patient, prescription and medication order management
- Validation and reconciliation workflows
- Alerts, operation history and scheduled automated tasks
- REST API backed by PostgreSQL and Prisma
- Automated tests with Vitest
- Continuous integration with GitHub Actions

#### Stack

`React` `Vite` `CSS Modules` `Node.js` `Express` `Prisma` `PostgreSQL` `Vitest` `GitHub Actions` `Render`

Multi-brand corporate web application developed to represent four different brands and business areas from a shared React codebase.

- Reusable component architecture and shared layouts
- Dedicated routes for each brand using React Router
- Responsive design across desktop, tablet and mobile
- Internationalisation support
- Lazy-loaded routes and components
- Deployment through Vercel

`React` `Vite` `React Router` `JavaScript` `CSS Modules` `ESLint` `Vercel`
